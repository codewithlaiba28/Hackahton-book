# Quickstart: Urdu Language Toggle

This document provides a quick overview of how to use the Urdu language toggle feature.

## Switching to Urdu

1.  Navigate to any documentation chapter page.
2.  If an Urdu version of the chapter is available, a toggle button labeled "Urdu" will be visible at the top of the page.
3.  Click the "Urdu" button to switch to the Urdu version of the chapter.

## Switching back to English

1.  When viewing an Urdu chapter, a toggle button labeled "English" will be visible at the top of the page.
2.  Click the "English" button to switch back to the English version of the chapter.
